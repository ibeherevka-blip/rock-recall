# Rock Recall

Статический русскоязычный тренажёр для музыкальных квизов. Во время занятия нет нейросети, сервера приложения, внешних API или регистрации. Прогресс и настройки хранятся в `localStorage` текущего браузера; при очистке данных сайта они удаляются. Устройства не синхронизируются.

- **Темы:** все локальные обложки студийных альбомов из базы, фото групп, вокалисты, переводы названий, дебютные альбомы, факты и сбалансированный микс.
- **Учить:** вспомнить ответ, открыть карточку, оценить себя. Ошибка возвращается один раз в той же тренировке; правильные ответы откладываются на 1, 2, 4 и далее дней (до 90).
- **Квиз:** до 10 вопросов, примерно поровну с вариантами и свободным ответом. Сверка не учитывает регистр, акценты и пунктуацию; если ответ верен по смыслу, его можно засчитать вручную. Итог — первые попытки и разбор ошибок.

## Локальный запуск

```sh
python -m http.server 8080 --bind 127.0.0.1 --directory docs
```

Открыть `http://127.0.0.1:8080`. Для GitHub Pages публиковать папку `/docs` из `main`. Корневые исходники и локальный отчёт не нужны сайту. В проекте с относительными путями он также работает под подпутём репозитория.

## Обновление вопросов из Obsidian

```sh
python -m pip install -r requirements.txt
python tools/export.py --vault '/path/to/Полный_рок_eng'
python -m unittest discover -s tests
node --test tests/engine.test.mjs
```

Экспорт только читает папку источника. Для пробы: `--limit 8 --out /path/to/empty/output`. Готовая публичная выгрузка: `docs/deck.json`, `docs/assets/`. Служебные комментарии повторений, настройки Obsidian, источники вне выбранных полей и оригинальные заметки не копируются. Отчёт `export-report.local.json` содержит внутренние пути и не коммитится. Вопросы наследуют данные источника и не прошли индивидуальную фактологическую проверку. Перед публикацией убедись, что у тебя есть право распространять выбранные изображения.
